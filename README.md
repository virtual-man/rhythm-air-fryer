# Rhythm Air Fryer

Public CMF concept site for a 5.5L compact air fryer.

- Body: Slow Swing `#2C3241` matte powder
- Window: Mellow Flow `#95A7B4` etched glass
- Accent: Free Groove `#024A7F` on the pull ring only
